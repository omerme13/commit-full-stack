Full Stack Coding Task (React + Node.js)
Objective
Build a simple full-stack application that retrieves a list of fruits from a backend API and displays it in a React application.
Requirements
Backend
Use Node.js with Express or NestJS.
Create the following endpoint:
GET /api/fruits
The endpoint should return a list of fruits.
Frontend
Using React, create a page that:
Fetches the list of fruits from the backend.
Displays the fruits as either a list or cards.
Shows a loading indicator while the data is being fetched.
Displays an error message if the request fails.
Bonus
Add a search input that filters the fruits by name
